\begin{abstract}
%
%Sophisticated data augmentations  can greatly boost the efficiency of Graph Contrastive Learning. %, especially on large graphs.
%
Although  augmentations (\eg, perturbation of graph edges, image crops)  boost the efficiency of Contrastive Learning (CL), feature level augmentation is another plausible, complementary yet not well researched strategy. 
%sophisticated non-random sampling data augmentation can greatly affect the efficiency of GCL, especially on large graphs.
%
%There exist feature augmentation strategies for unsupervised contrastive learning, although (class-conditional) feature augmentation has been proven useful in supervised learning. %  by introducing conditional probabilities.
% Feature Augmentation (FA) is emerging as a promising tool in learning robust representation for contrastive learning (CL). However, some popular approaches like dropout and batch norm in other domains do not work very well on graphs and scarcely any work has been conducted to investigate the potential benefit of introducing feature augmentation in graph contrastive learning (GCL).
%
%In this paper, we present a novel and efficient feature argumentation approach for contrastive learning on graphs, which estimates a low-rank approximation for given feature maps as errors and then Subtract errors from given feature maps, which is able to help feature alignment between two different views.
%
Thus, we present a novel spectral feature argumentation for contrastive learning on graphs (and images). To this end, for each data view, we estimate a low-rank approximation per feature map and  subtract that approximation from the map to obtain its complement. This is achieved by the proposed herein  incomplete power iteration, a non-standard power iteration regime which enjoys two valuable byproducts (under mere one or two iterations): (i) it partially balances spectrum of the feature map, and (ii) it injects the noise into rebalanced singular values of the feature map (spectral augmentation). 
%
%
For two views, we align these rebalanced feature maps as such an improved alignment step can focus more on less dominant singular values of matrices of both views, whereas the spectral augmentation does not affect the spectral angle alignment (singular vectors are not perturbed). 
%
We derive the analytical form for: (i) the incomplete power iteration to capture its spectrum-balancing effect, and (ii) the variance of singular values  augmented implicitly by the noise. We also show that the spectral augmentation improves the generalization bound. 
%
 % which results in the performance boost. %which helps the feature alignment between two different views.
%
%
% We show that our approach refines the so-called eigenspace alignment of two correlated graph views via assigning a smaller/larger scale factor to a larger/smaller singular value of the features maps, enforcing the contribution of eigenvectors for alignment to be more balanced.
%
Experiments on graph/image datasets show that our spectral feature augmentation  outperforms %its corresponding 
baselines, and is complementary with other  augmentation strategies and compatible with various contrastive losses. %in GCL, 
%and  compatible with different contrastive loss functions.

\end{abstract}
