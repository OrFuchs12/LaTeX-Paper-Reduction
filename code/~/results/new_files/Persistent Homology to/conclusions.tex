
\section{Conclusion}
\label{sec:conclusions}
Topological data analysis can be an effective tool to mine for higher order structural information from point cloud data. In this paper, we presented a persistent homology based framework to analyze and glean various types of structural information from a cold hardiness data set. The framework itself is generic and can be extended to other applications within agriculture or other domains.
Future research directions include (but are not limited to) a) using the information gained to improve the prediction accuracy of cold hardiness models; b) adverse testing against noise and incomplete data; and c) exploring ways to use relationships inferred toward data imputation and multi-task learning among cultivars.
